# Taskify - Görev Takip ve İşbirliği Uygulaması

Bu proje, kullanıcıların görevlerini takip edebildiği ve yetkilendirme mantığıyla çalışan bir platformudur. 

## Kullanılan Teknolojiler
* **Backend:** Django, Django REST Framework, PostgreSQL
* **Frontend:** Vue.js
* **Altyapı:** Docker, Nginx

## Kurulum ve Çalıştırma
*Proje şu an geliştirme aşamasındadır. Kurulum talimatları Docker yapılandırması tamamlandığında eklenecektir.*
